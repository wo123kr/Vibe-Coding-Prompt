# SYNERGY — AI 협업 개발 프롬프트

LLM에게 바로 코드를 쓰게 하지 않고 **설계(Blueprint)에 먼저 합의한 뒤 구현(Build)** 하게 만드는 시스템 프롬프트입니다. ChatGPT·Claude·Gemini 어디에나 붙여 넣어 씁니다.

프롬프트 본문: [`synergy-v1.md`](synergy-v1.md)

## 왜 만들었나

"로그인 페이지 만들어 줘"라고 하면 LLM은 곧바로 코드를 내놓습니다. 범위와 제약을 합의하지 않은 코드라 몇 번 오가면 설계가 흐트러지고, 어디까지 했는지도 흐려집니다. 사람과 일할 때처럼 **계획을 먼저 맞추고, 단계마다 설명을 받는** 흐름을 프롬프트로 고정했습니다.

## 어떻게 동작하나

**1단계 · Blueprint** — 새롭거나 복잡한 요청이면 코드를 쓰기 전에 계획부터 제안합니다.

| 항목 | 내용 |
|---|---|
| 목표 | 이 작업이 끝나면 무엇이 되는가 |
| 범위 | 할 것과 하지 않을 것 |
| 단계 | 실행 가능한 작업 순서 |
| 품질·제약 | 테스트·성능·보안·접근성 |
| 파일 | 만들거나 고칠 파일 예측 |

**2단계 · Build** — 계획에 동의하면 단계별로 구현하고, 매번 같은 틀로 답합니다.

- **Vibe-Check** — 어떤 생각으로 이렇게 짰는지
- **Proposed Code** — 주석이 달린 코드
- **Explanation** — 핵심 로직과 설계 의도
- **Next Steps** — 테스트·예외 처리·개선점

## 쓰는 법

1. [`synergy-v1.md`](synergy-v1.md) 전체를 복사합니다.
2. 새 대화의 첫 메시지로 붙여 넣습니다.
3. 준비됐다는 답이 오면 작업을 요청합니다. 예: "내 React 프로젝트에 로그인 페이지를 추가하고 싶어."

## 설계 메모

- 작은 수정까지 계획을 세우면 느려지므로, Blueprint는 **새롭거나 복잡한 요청**에만 걸리게 했습니다.
- 매 답변을 같은 네 칸(Vibe-Check → Code → Explanation → Next Steps)으로 고정해, 긴 대화에서도 진행 단계가 보이게 했습니다.
